# Лендинг Traty

Рекламная страница приложения на трёх языках. Живёт отдельно от `web/` (там
хостинг Firebase с политикой и удалением аккаунта) и от витрины Play.

```bash
python3 build.py          # собрать страницы
python3 build.py --check  # только проверить, что плейсхолдеры закрыты
```

Страница опубликована на **https://charly3x.github.io/traty/** (GitHub Pages,
ветка `main`, корень). Пути внутри начинаются с `/traty`, поэтому локально
смотреть нужно через такой же префикс:

```bash
mkdir -p /tmp/preview && ln -sfn "$PWD" /tmp/preview/traty
cd /tmp/preview && python3 -m http.server 4173   # localhost:4173/traty/
```

Префикс, состав языков и корневой язык задаются в `content/site.json`.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `template.html` | разметка, стили и сценарий — один на все языки |
| `content/<язык>.json` | все тексты и все числа этого языка |
| `content/site.json` | адрес, по которому страница будет жить |
| `build.py` | подстановка: шаблон + словарь → готовая страница |
| `tools/` | генераторы словарей: считают суммы из демо-набора |
| `assets/<язык>/` | снимки экранов и картинка для соцсетей |
| `index.html`, `pl/`, `uk/` | **собранные** страницы, руками не править |

Правка текста — в `content/<язык>.json`, потом `build.py`. Правка вёрстки — в
`template.html`, потом `build.py`. Собранные файлы перезаписываются целиком.

## Язык и валюта связаны

Английская страница показывает евро, польская — злотые, украинская — гривны.
Это не косметика: рядом с макетом стоит снимок экрана приложения, и разные
валюты в них читаются как подделка.

Числа в макетах — тот же демо-набор, по которому сняты экраны
(`scripts/demo_locales.py`): у польского курс 1, у украинского 11, у
английского 0,25 к злотому. Меняете набор — пересоберите словари:

```bash
python3 landing/tools/make_en.py && python3 landing/tools/make_pl_uk.py
python3 landing/build.py
```

Английские экраны пересняты 17.09.2026 в евро: у локали `en` в
`scripts/demo_locales.py` теперь `EUR`, курс 0,25 к злотому и английские
названия магазинов. Числа на странице списаны с этих снимков, а не посчитаны
заново, — см. шапку `tools/make_en.py`.

Дробная часть везде через запятую, включая английскую страницу: приложение
печатает её так в любом языке (`formatFixedPoint` в `lib/utils/fixed_point.dart`),
и страница обязана совпадать со снимком рядом.

## Что проверить перед публикацией

1. **Адрес.** `content/site.json` — от него считаются canonical, hreflang,
   Open Graph, `sitemap.xml` и `robots.txt`.
2. **Ссылка на Play.** В `content/*.json` поле `play`. Сейчас стоит адрес по
   имени пакета `dev.charoian.traty`.
3. **Цена подписки.** В `content/*.json` → `data.plan`: `19,99 zł`, `149 ₴`,
   базовая `$4.99` (значения владельца, 16.09.2026). Цена упоминается ещё и в
   ответе `faq.a3` — правьте оба места через генераторы в `tools/`.
4. **Ссылки в подвале** (`privacyUrl`, `deleteUrl`) ведут на страницы Firebase
   Hosting — проверьте, что они открываются.

Пути к картинкам абсолютные (`/assets/...`), потому что страницы лежат в
подкаталогах `/pl/` и `/uk/`. Из-за этого открыть файл двойным щелчком
(`file://`) нельзя — нужен любой веб-сервер, хоть `python3 -m http.server`.

## Чего на странице нет и почему

Отзывов, оценок, числа установок и логотипов магазинов. Всё это — утверждения о
мире, которых у нас нет; выдуманный отзыв в рекламе стоит дороже, чем пустое
место на странице. Числа, которые есть (30 категорий, 4 языка, 5 бесплатных
распознаваний, 20 в сутки, 100 в месяц, семья до пяти), взяты из
[docs/tiers.md](../docs/tiers.md) и кода.
